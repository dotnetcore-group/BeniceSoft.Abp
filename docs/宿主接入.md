# 宿主接入

样例：`samples/BeniceSoft.Abp.Sample.Host/SampleHostModule.cs`。

## 模块

| 能力 | `DependsOn` |
|------|-------------|
| 统一响应、异常、文化映射 | `BeniceSoftAbpAspNetCoreModule` |
| Swagger | `BeniceSoftAbpSwaggerModule` |
| JWT / 功能权限 | `BeniceSoftAbpAuthModule` |
| 缓存 | `BeniceSoftAbpCachingMessagePackModule` 或 `BeniceSoftAbpCachingSystemTextJsonModule` |
| 分布式锁 | `BeniceSoftAbpDistributedLockModule` |
| 限流 | `BeniceSoftAbpRateLimitingModule` |
| 操作日志（事件总线） | `BeniceSoftAbpOperationLoggingEventBusModule` |
| 操作日志（Redis Pub/Sub） | `BeniceSoftAbpOperationLoggingRedisModule` |
| 变更审计 | `BeniceSoftAbpAuditTrailEventBusModule` |
| DTM HTTP | `BeniceSoftAbpEventBusDtmHttpModule` |
| DTM EF outbox/inbox | `BeniceSoftAbpEventBusDtmEntityFrameworkCoreModule` |
| RabbitMQ 作业队列 | `BeniceSoftAbpRabbitMqModule` |
| 声明式拦截 | `AbpAutofacModule` |

EF：`BeniceSoftAbpEntityFrameworkCorePostgreSqlModule` 或 `BeniceSoftAbpEntityFrameworkCoreSqlServerModule`。分片加 `BeniceSoftAbpEntityFrameworkCoreShardingModule`。

```csharp
context.Services.AddBeniceSoftAuthentication();
context.Services.AddBeniceSoftAuthorization();
```

常规 Controller：`Configure<AbpAspNetCoreMvcOptions>` → `ConventionalControllers.Create(应用层程序集)`，`RootPath` 为路由前缀。

## 中间件

```csharp
app.UseCorrelationId();
app.UseRouting();
app.UseBeniceSoftExceptionHandlingMiddleware();
app.UseAbpRequestLocalization();
app.UseDtmHttpMiddleware();          // DTM 回调，在认证之前
app.UseBeniceSoftAuthentication();
app.UseMultiTenancy();
app.UseBeniceSoftAuthorization();
app.UseBeniceSoftUserPermission();   // 在认证、授权之后
app.UseBeniceSoftSwagger();
app.UseConfiguredEndpoints(endpoints =>
{
    endpoints.MapServiceDiscoveryHealthCheck();
});
```

未使用的中间件不注册。未调用 `UseBeniceSoftUserPermission` 时，功能权限、字段权限、行权限为空。

迁移导出 SQL 后手工执行。启动时不调用 `Database.Migrate()`。

## 配置节

| 节 | 用途 |
|----|------|
| `ConnectionStrings:Default` | 默认库 |
| `Auth:Authority` | JWT 校验、机器身份换 token，填网关地址 |
| `Auth:PermissionCenterUrl` | 拉取用户数据权限，填网关地址 |
| `Auth:ClientId` / `ClientSecret` / `Scope` | 服务间 `client_credentials`，默认 scope `api` |
| `Redis:Configuration` | 缓存、限流 |
| `BeniceSoft:Caching:CacheKeyPrefix` / `DefaultExpirationSeconds` | 缓存前缀、默认 TTL |
| `DistributedLock:ConnectionString` | 锁专用 Redis，与 `Redis:Configuration` 分开 |
| `RateLimiting` | `KeyPrefix`（默认 `ratelimit`）、`Enabled`、`DefaultMessage` |
| `RabbitMQ:Connections` / `RabbitMQ:EventBus` | ABP 连接池 |
| `EventBus` | DTM：`DTM:AppUrl`、`DtmUrl`、`DbContextName` |
| `RemoteServices` | 动态 HTTP 客户端 BaseUrl |
| `ServiceDiscovery` | 注册名、`GatewayBaseUrl`、元数据 |
| `Smtp` | 邮件 |
| `ObjectStorage` | 对象存储 |

Swagger 的 `Title` / `Version` 在 `PreConfigure<BeniceSoftSwaggerOptions>` 中设置。
