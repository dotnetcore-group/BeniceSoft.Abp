# 变更审计

SaveChanges 采集标有 `[AuditTracked]` 的属性变更，成功后发布 `EntityChangeEvent`。

Host 依赖 `BeniceSoftAbpAuditTrailEventBusModule`。默认 `Enabled = false`。

```csharp
Configure<BeniceSoftAbpAuditTrailOptions>(options =>
{
    options.Enabled = true;
    options.ExcludedEntityTypes.Add(nameof(SomeEntity));
});
```

DbContext 继承 `BeniceSoftAbpDbContext`。事件名 `BeniceSoft.KA.EntityChangeEvent`。订阅：`IDistributedEventHandler<EntityChangeEvent>`。

`ExcludedEntityTypes` 为实体类型名。采集可在子类重写 `CaptureAuditTrailChanges()`。

特性标在属性上：

```csharp
[AuditTracked(DisplayName = "状态")]
public int Status { get; private set; }
```

`DisplayName` 为空时使用属性名。记录包含 `EntityType`、`EntityId`、`ChangeType`（`Added` / `Modified` / `Deleted`）、`OperatorId`、`OperatorName`、`ChangeTime`、属性前后值。操作人取自 `IBeniceSoftCurrentUser`；无当前用户时 `OperatorId`、`OperatorName` 为空。

Bulk 不进入 ChangeTracker，不产生变更记录。
