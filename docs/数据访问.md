# 数据访问

包：`BeniceSoft.Abp.EntityFrameworkCore`，加上 PostgreSQL 或 SqlServer 提供程序。分片见[分库分表使用指南](./分库分表使用指南.md)。

## DbContext

```csharp
[ConnectionStringName("Default")]
public class WarehouseCenterDbContext : BeniceSoftAbpDbContext<WarehouseCenterDbContext>
{
    public WarehouseCenterDbContext(DbContextOptions<WarehouseCenterDbContext> options) : base(options)
    {
    }

    public virtual DbSet<Warehouse> Warehouses { get; set; }

    protected override NamingConvention NamingConvention => NamingConvention.SnakeCase;

    protected override void OnBeniceSoftModelCreating(ModelBuilder modelBuilder)
    {
        modelBuilder.ConfigureWarehouseAggregate();
    }
}
```

默认 `NamingConvention.None`，列名与属性名一致。`SnakeCase`、`LowerCase`、`CamelCase` 在子类重写。`OnConfiguring` 已调用 `UseNamingConvention` 和 `UseNoRelation`，关系在 Fluent API 配置。

`ToTable` 写逻辑表名。启用命名约定后，物理列名由约定生成。

```csharp
[DependsOn(typeof(BeniceSoftAbpEntityFrameworkCorePostgreSqlModule))]
public class YourEntityFrameworkCoreModule : AbpModule
{
    public override void ConfigureServices(ServiceConfigurationContext context)
    {
        context.Services.AddAbpDbContext<YourDbContext>(options =>
        {
            options.AddDefaultRepositories(includeAllEntities: true);
        });

        Configure<AbpDbContextOptions>(options =>
        {
            options.Configure<YourDbContext>(ctx => ctx.UseNpgsql());
        });
    }
}
```

## 主键

```csharp
builder.Property(e => e.Id)
    .ValueGeneratedOnAdd()
    .HasValueGenerator<SnowDateIdGenerator>();
```

`long` 主键用 `SnowDateIdGenerator`。带前缀的字符串号：`HasValueGenerator<TGenerator>(prefix)`。

## Bulk

`BulkInsertAsync` / `BulkUpdateAsync` / `BulkDeleteAsync` / `BulkMergeAsync` 不经 ChangeTracker，不填审计字段。调用方自行设置 `Id` 和审计值。

PostgreSQL 与 SqlServer 方法名相同。列构建类型分别为 `NpgsqlBulkAtom<T>`、`SqlServerBulkAtom<T>`。

```csharp
await db.BulkInsertAsync(orders);
await db.BulkUpdateAsync(orders, matchBuilder: m => m.MatchTargetOn(x => x.Id));
await db.BulkMergeAsync(orders, matchBuilder: m => m.MatchTargetOn(x => new { x.OrderNo, x.WarehouseId }));
await db.BulkDeleteAsync(orders, matchBuilder: m => m.MatchTargetOn(x => x.Id));
```

未调用 `MatchTargetOn` 时，Update / Delete / Merge 用实体主键。列裁剪用 `tableBuilder`。

普通 `SaveChanges` 的并发冲突：`ForceSaveChangeAsync`，默认重试 2 次。

## QueryFuture

同一 `DbContext` 上的 `Future` / `FutureValue` 在首次取值时合并为一次往返。

```csharp
var orders = db.Orders.Where(x => x.WarehouseId == id).Future();
var count = db.Orders.Where(x => x.WarehouseId == id).FutureValue();

var total = count.Value;
var list = orders.ToList();
```

`QueryFutureManager.AllowQueryBatch == false` 时立即执行。

## Sequence 与 Hint

序列须已存在于数据库：

```csharp
var next = await db.Database.GetSequenceAsync<long>("order_no_seq");
var batch = await db.Database.GetSequenceAsync<long>("order_no_seq", 100);
```

PostgreSQL：`optionsBuilder.ForRowState()` 后，查询可 `ForUpdate()` / `ForShare()` / `ForHint()`。

SqlServer：`optionsBuilder.WithTableHint()` 后，查询可 `WithNoLock` / `WithReadPast` / `WithUpdLock` / `WithIndex`。Hint 只加在当前 `IQueryable` 上。
