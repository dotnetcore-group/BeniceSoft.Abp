# 认证与数据权限

JWT 来自 OpenIddict。用户 Id、姓名、租户从 Claims 读取。功能权限、字段权限、行权限由 PermissionCenter 下发。

模块：`BeniceSoftAbpAuthModule`。行权限仓储：`BeniceSoft.Abp.Auth.EntityFrameworkCore`。

## JWT

```json
"Auth": {
  "Authority": "http://gateway:5056",
  "PermissionCenterUrl": "http://gateway:5056"
}
```

`Authority` 用于校验 token，也用于机器身份换 token。`MapInboundClaims = false`，claim 类型保持 `sub` 等原始短名。

```csharp
context.Services.AddBeniceSoftAuthentication();
context.Services.AddBeniceSoftAuthorization();
```

`UseBeniceSoftUserPermission` 放在 `UseBeniceSoftAuthentication`、`UseBeniceSoftAuthorization` 之后。

服务间调用配置 `Auth:ClientId`、`ClientSecret`。三者与 `Authority` 都有值时走 `client_credentials`，地址 `{Authority}/connect/token`，scope 默认 `api`。

应用服务通过 `CurrentUser`（`IBeniceSoftCurrentUser`）读取当前用户。`TenantId` 为逻辑租户。物理按租户分库使用分片 `DataSourceRoute`，不使用 `MultiTenantConnectionStringResolver`。

## 机器 Token

`IMachineAccessTokenProvider` 定义在 `BeniceSoft.Abp.Auth.Core`，业务应用层通过该接口获取机器 Token。实现类为 `BeniceSoft.Abp.Auth.Authentication.MachineAccessTokenProvider`，由宿主加载的 `BeniceSoftAbpAuthModule` 按 ABP 约定注册为单例；用于获取 Token 的命名 HttpClient 也由该模块注册。

宿主继续调用 `AddBeniceSoftAuthentication()` 绑定 `Auth` 配置。获取、缓存及刷新 Token 使用同一个提供器，配置项及获取失败时返回 `null` 的行为保持不变。SDK 的 `BeniceSoftAbpHttpClientModule` 通过认证抽象消费该能力，业务应用层无需为了获取 Token 而依赖 SDK 代理模块。

接口与实现从原 `BeniceSoft.Abp.Http.Client` 程序集迁出后，直接消费接口的代码需要使用 `BeniceSoft.Abp.Auth.Core` 命名空间。升级时同步更新 `Auth.Core`、`Auth`、`Http.Client` 等框架包到同一已发布版本，宿主仍需加载认证模块，避免混用包含旧类型的程序集。

## 功能权限

```csharp
[FunctionPermission("Warehouse.Order.Create")]
public virtual Task CreateAsync(CreateOrderInput input) => Task.CompletedTask;

[FunctionPermission("Warehouse.Order.Update", "Warehouse.Order.Audit")]
public virtual Task UpdateAsync(UpdateOrderInput input) => Task.CompletedTask;
```

可标在类或方法上。多个权限码为或关系。都不具备时返回 `ForbidResult`（403）。

当前请求的权限：`ICurrentUserPermissionAccessor`。仅在 `UseBeniceSoftUserPermission` 之后有值。

## 字段权限

属性上的格式为 `表名.字段名`。无权限时写成 `maskedValue`，默认 `"0"`。

```csharp
public class OrderDto
{
    [FieldAuth("wh_orders.amount")]
    public decimal Amount { get; set; }

    [FieldAuth("wh_orders.cost", "***")]
    public string Cost { get; set; } = string.Empty;
}
```

Action 加 `[FieldAuthFilter]`，处理 `ObjectResult`。写入由 `BeniceSoftAbpAuthEntityFrameworkCoreModule` 的字段权限拦截器在 SaveChanges 中丢弃无权限字段的修改。

## 行权限

```csharp
services.AddRowPermissionRepositories<WarehouseCenterDbContext>();
```

按 DbContext 的 `DbSet<>` 注册 `IRowPermissionRepository<TEntity>`，主键默认 `long`。该仓储的 `GetQueryableAsync()` 带行权限谓词。

```csharp
var all = await rowRepo.GetQueryableWithoutRowFilterAsync();
```

`IRepository.GetQueryableAsync()` 不含行权限。
