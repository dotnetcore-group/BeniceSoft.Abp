# 消息与事务

作业队列使用 `BeniceSoft.Abp.Extensions.RabbitMQ`。分布式事件、TCC、SAGA 使用 DTM，配置节 `EventBus`。

## RabbitMQ 作业队列

`DependsOn(typeof(BeniceSoftAbpRabbitMqModule))`。连接使用 ABP `RabbitMQ:Connections`。队列名在代码中指定。

```csharp
context.Services.AddRabbitWorkConsumer<OrderImportMessage, OrderImportHandler>(options =>
{
    options.QueueName = "order.import";
    options.PrefetchCount = 10;
});

public class OrderImportHandler : IRabbitMessageHandler<OrderImportMessage>
{
    public Task<RabbitMessageResult> HandleAsync(
        OrderImportMessage message,
        IReadOnlyBasicProperties properties,
        CancellationToken cancellationToken = default)
        => Task.FromResult(RabbitMessageResult.Success);
}
```

`RabbitMessageResult`：

| 值 | 行为 |
|----|------|
| `Success` | ACK |
| `Requeue` | 立即重新入队 |
| `Redelivery` | 投到队列尾部 |
| `DeadLetter` | 拒绝，不入队 |

瞬时失败抛 `RabbitTransientException`。进死信抛 `RabbitDeadLetterException`。

`PrefetchCount` 是通道未 ACK 上限，默认 1。大于 1 时同一 Handler 并发处理。`MaxRedeliveryTimes <= 0` 表示不限制 Redelivery 次数。`ConnectionName` 对应 `RabbitMQ:Connections` 中的连接名，默认 `Default`。

```csharp
using var publisher = serviceProvider.CreateWorkPublisher("order.import");
await publisher.PublishAsync(message);
```

Fanout / Direct / Topic：`RabbitRelational.Fanout` / `Direct` / `Topic`，再 `CreatePublisher(relational)`。

## DTM

`BeniceSoftAbpEventBusDtmHttpModule` 处理 HTTP 回调。`BeniceSoftAbpEventBusDtmEntityFrameworkCoreModule` 提供 outbox / inbox。

```json
"EventBus": {
  "Type": "DTM",
  "DTM": {
    "AppUrl": "http://gateway:5056",
    "DtmUrl": "http://dtm:36789",
    "DbContextName": "WarehouseCenterDbContext"
  }
}
```

`AppUrl` 是 DTM 回调本服务的地址。经网关时填网关地址，`[DtmBranch].ServiceName` 与 `ServiceDiscovery:ServiceName` 相同。`DbContextName` 为本服务 DbContext 类名。

`UseDtmHttpMiddleware()` 放在认证之前。回调路径：`/dtm_boxes.DtmHttpService/tcc`、`/dtm_boxes.DtmHttpService/saga`。

`EventBus:Type` 为 `DTM` 时，`IDistributedEventBus.PublishAsync` 走 outbox。

### TCC

请求实现 `IBranchRequest`，并标记 `[DtmBranch(serviceName, handlerName)]`。Handler 实现 `ITccBranchCallbackHandler<TRequest>`：`TryAsync`、`ConfirmAsync`、`CancelAsync`。

```csharp
[DtmBranch("order-service", "order-create")]
public class CreateOrderRequest : IBranchRequest
{
    public string BizId { get; set; } = string.Empty;
}
```

```csharp
context.Services.AddDtmCallbackHandlersFromAssemblies(typeof(CreateOrderHandler).Assembly);

await globalTransaction.ExecuteTccAsync(async tcc =>
{
    await tcc.CallBranchAsync(new CreateOrderRequest { BizId = bizId });
});
```

`CallBranchAsync` 未传 `serviceName` / `handlerName` 时，从 `[DtmBranch]` 读取。Try 阶段抛异常后，DTM 调用 Cancel。

### SAGA

请求同样实现 `IBranchRequest` 并标记 `[DtmBranch]`。Handler 实现 `ISagaBranchCallbackHandler<TRequest>`：`ActionAsync`、`CompensateAsync`。

```csharp
await globalTransaction.ExecuteSagaAsync(saga =>
{
    saga.AddBranchByHandler(request);
    return Task.CompletedTask;
});
```

`AddDtmCallbackHandlersFromAssemblies` 同时注册 TCC 与 SAGA Handler。
