# 分库分表使用指南（业务服务接入）

本文说明如何在 **Wecharmer 业务微服务** 中为「某一个表」启用分表 / 分库能力。  
示例服务以 **`Wecharmer.WarehouseCenter`** 的现有工程结构为模板；假设要给该服务新增 **B2C 订单表**（`B2cOrder`）并按月分表。

> **说明**
>
> - 这是**接入文档**，文中路径与类名按该服务习惯书写，复制到真实服务后改名即可。
> - **建表规范：先 Migration 后 Compensate**（详见 §0；）。
> - 可运行的业务模板：`BeniceSoft.Abp/samples`（EF 模块内直接 `AddSharding` + `UseShardingAfter`；Host 启动 `Migrate` → `UseCompensate`）。
> - 引擎边界/单元测试：`tests/BeniceSoft.Abp.EntityFrameworkCore.Sharding.Tests`。
> - Sample 相关自动化（Bulk 等）：`tests/BeniceSoft.Abp.Sample.Tests`。
> - 包：`BeniceSoft.Abp.EntityFrameworkCore.Sharding`。

---

## 0. 先想清楚：你要分什么？

| 目标 | 做什么 | 注册什么 |
|------|--------|----------|
| **只分表**（同一库多物理表） | 按月 / 取模等切表 | 只 `AddTableRoute<...>` |
| **只分库**（多物理库） | 按区域 / 租户键等切库 | 只 `AddDataSourceRoute<...>` |
| **分库 + 分表** | 先落库再落表 | 两个路由都注册 |

**建表规范（固定顺序）：**

1. 创建实体 + `ToTable`（逻辑表名）。
2. 生成 Migration；用 `dotnet ef database update` **或**导出 SQL 并执行 → **实体物理表已存在**。
3. 若该实体需要分片：编写 `TableRoute`（及分库时的 `DataSourceRoute`）并注册。
4. 启动应用：先 `Migrate()`，再 `UseCompensate()` → **只创建带后缀的分片物理表**。
5. **禁止**在 `Migrate` 之前调用 `UseCompensate`。

**其它原则：**

1. **只给需要分片的实体注册路由**；仓库、库位、商品等普通表**不要** `AddTableRoute` / `AddDataSourceRoute`。壳 DbContext 可同时有分片实体与普通实体；未注册路由的走**默认库 + 逻辑表名**。
2. 查询尽量带**分片键等值条件**；无谓词会扇出多表再合并。
3. 已落库行**不要改分片键字段值**。
4. 若启用多物理库：**同一次 UoW / SaveChanges 不要跨库提交**。
5. **分片 DbContext 不要叠** ABP 按租户切换连接串（`MultiTenantConnectionStringResolver`）；逻辑多租户可保留，物理按租户分库用 `DataSourceRoute`。

下文主流程 = **WarehouseCenter + B2C 订单按月分表（单库）**。文末附「可选：分库」步骤。

## 2. Domain：新增 B2C 订单实体（带分片键）

路径示例：

`src/Wecharmer.WarehouseCenter.Domain/AggregateModels/OrderAggregate/B2cOrder.cs`

```csharp
using BeniceSoft.Abp.Ddd.Domain.Entity;

namespace Wecharmer.WarehouseCenter.Domain.AggregateModels.OrderAggregate;

/// <summary>
/// B2C 订单（本服务启用分表的实体示例）。
/// 分片键：OrderTime → 物理表 wh_b2c_orders_yyyyMM
/// </summary>
public class B2cOrder : BeniceSoftFullAuditedMultiTenantAggregateRoot<long>
{
    /// <summary>订单号</summary>
    public string OrderNo { get; private set; } = string.Empty;

    /// <summary>金额</summary>
    public decimal Amount { get; private set; }

    /// <summary>
    /// 分片键：下单时间（按月切表）。
    /// 业务约定：行写入后不要修改此字段值。
    /// </summary>
    public DateTime OrderTime { get; private set; }

    protected B2cOrder()
    {
    }

    public B2cOrder(long id, string orderNo, decimal amount, DateTime orderTime)
    {
        Id = id;
        OrderNo = orderNo;
        Amount = amount;
        OrderTime = orderTime;
    }
}
```

分片键选型建议：

- **按月分表**：用稳定的业务时间（下单时间 / 记账月），不要用「经常变更」的字段值。
- **取模分表**：用业务桶号 / 用户 Id 取模等整数键（见文末路由变体）。

## 3. EF：配置逻辑表名（不含物理后缀）

路径示例：

`src/Wecharmer.WarehouseCenter.EntityFrameworkCore/EntityTypeConfigurations/B2cOrderTypeConfiguration.cs`

```csharp
using BeniceSoft.Core.Strategy;
using Microsoft.EntityFrameworkCore;
using Microsoft.EntityFrameworkCore.Metadata.Builders;
using Wecharmer.WarehouseCenter.Domain.AggregateModels.OrderAggregate;

namespace Wecharmer.WarehouseCenter.EntityTypeConfigurations;

internal static class B2cOrderTypeConfiguration
{
    internal static void ConfigureB2cOrder(this ModelBuilder modelBuilder)
    {
        modelBuilder.Entity<B2cOrder>(builder =>
        {
            // 只写逻辑表名；物理后缀 _yyyyMM 由分片路由追加
            builder.ToTable(EfConstants.TablePrefix + "b2corders", t => t.HasComment("B2C订单（按月分表）"));
            builder.HasKey(e => e.Id);

            builder.Property(e => e.Id).ValueGeneratedOnAdd().HasValueGenerator<SnowDateIdGenerator>();
            builder.Property(e => e.OrderNo).IsRequired().HasMaxLength(64);
            builder.Property(e => e.Amount).IsRequired();
            builder.Property(e => e.OrderTime).IsRequired().HasComment("分片键-下单时间");

            builder.HasIndex(e => e.OrderNo);
            builder.HasIndex(e => e.OrderTime);
        });
    }
}
```

在 `WarehouseCenterDbContext.OnBeniceSoftModelCreating` 中调用：

```csharp
modelBuilder.ConfigureWarehouseAggregate();
modelBuilder.ConfigureB2cOrder(); // 新增
```

并增加 DbSet：

```csharp
public virtual DbSet<B2cOrder> B2cOrders { get; set; }
```

## 4. 改造壳 DbContext 基类（一次性）

**现状（WarehouseCenter）：**

```csharp
public class WarehouseCenterDbContext : BeniceSoftAbpDbContext<WarehouseCenterDbContext>
```

**改为（启用分片能力后）：**

```csharp
using BeniceSoft.Abp.EntityFrameworkCore;
using BeniceSoft.Abp.EntityFrameworkCore.Sharding;
using Microsoft.EntityFrameworkCore;
using Volo.Abp.Data;
using Wecharmer.WarehouseCenter.Domain.AggregateModels.OrderAggregate;
using Wecharmer.WarehouseCenter.Domain.AggregateModels.WarehouseAggregate;
using Wecharmer.WarehouseCenter.EntityTypeConfigurations;

namespace Wecharmer.WarehouseCenter;

[ConnectionStringName("Default")]
public class WarehouseCenterDbContext
    : BeniceSoftShardingAbpDbContext<WarehouseCenterDbContext>, IShardingTableDbContext
{
    protected override NamingConvention NamingConvention => NamingConvention.LowerCase;

    public WarehouseCenterDbContext(DbContextOptions<WarehouseCenterDbContext> options)
        : base(options)
    {
    }

    #region DbSets

    public virtual DbSet<Warehouse> Warehouses { get; set; }
    public virtual DbSet<WarehouseZone> WarehouseZones { get; set; }
    public virtual DbSet<WarehouseLocation> WarehouseLocations { get; set; }

    /// <summary>B2C 订单（分表）</summary>
    public virtual DbSet<B2cOrder> B2cOrders { get; set; }

    #endregion

    /// <summary>由分片引擎赋值，业务代码无须赋值。</summary>
    public IRouteTail RouteTail { get; set; } = null!;

    protected override void OnBeniceSoftModelCreating(ModelBuilder modelBuilder)
    {
        modelBuilder.ConfigureWarehouseAggregate();
        modelBuilder.ConfigureB2cOrder();
    }
}
```

要点：

- 继承 `BeniceSoftShardingAbpDbContext<T>`（ABP + 分片壳）。
- 有**分表**实体时实现 `IShardingTableDbContext`，声明 `IRouteTail RouteTail`。
- 仓库等实体**保持原样**，无需改映射。

## 5. 写表路由（只注册 B2C 订单）

路径示例：

`src/Wecharmer.WarehouseCenter.EntityFrameworkCore/Sharding/B2cOrderMonthRoute.cs`

```csharp
using BeniceSoft.Abp.EntityFrameworkCore.Sharding;
using Wecharmer.WarehouseCenter.Domain.AggregateModels.OrderAggregate;

namespace Wecharmer.WarehouseCenter.Sharding;

/// <summary>
/// B2C 订单按月分表：wh_b2c_orders_yyyyMM（如 wh_b2c_orders_202401）
/// </summary>
public sealed class B2cOrderMonthRoute : MonthTailTableRoute<B2cOrder>
{
    /// <summary>必须为 true，否则 AsRoute 的 Must/Hint 不生效。</summary>
    protected override bool EnabledHint => true;

    public override void Configure(EntityMetadataTableBuilder<B2cOrder> builder)
    {
        builder.WithProperty(x => x.OrderTime)
            .WithSeparator("_")
            .WithAutoCreate(true); // 缺物理表时允许自动创建（生产可按规范关闭）
    }

    /// <summary>
    /// 历史最早可路由月份。
    /// 启动补偿会从该月建到当前月（物理表）。
    /// </summary>
    protected override DateTime GetBeginTime() => new(2024, 1, 1);

    /// <summary>默认 MonthTail 是 yyMM；业务使用四位年 yyyyMM。</summary>
    protected override string GetTail(DateTime date) => $"{date:yyyyMM}";
}
```

**不要**给 `Warehouse` / `WarehouseLocation` 写路由。

## 6. 写注册（AddSharding + UseShardingAfter；Host 调 UseCompensate）

业务服务可把 `AddSharding` 写在独立 Registrar，也可像 Sample 一样直接写进 EF Module。下面给扁平 Registrar 模板（**不要**再包一层 `UseNpgsqlWithSharding` / `Compensate`）。

路径示例：

`src/Wecharmer.WarehouseCenter.EntityFrameworkCore/Sharding/WarehouseCenterShardingRegistrar.cs`

```csharp
using BeniceSoft.Abp.EntityFrameworkCore.Sharding;
using Microsoft.EntityFrameworkCore;
using Microsoft.EntityFrameworkCore.Diagnostics;
using Microsoft.Extensions.Configuration;
using Microsoft.Extensions.DependencyInjection;

namespace Wecharmer.WarehouseCenter.Sharding;

/// <summary>
/// WarehouseCenter 分片注册：只给 B2cOrder 配表路由；其余实体普通表。
/// </summary>
public static class WarehouseCenterShardingRegistrar
{
    public const string DefaultDataSourceName = "ds0";

    public static void Configure(IServiceCollection services, IConfiguration configuration)
    {
        var cs = configuration.GetConnectionString("Default")
                 ?? throw new InvalidOperationException("ConnectionStrings:Default is required.");

        services.AddSharding<WarehouseCenterDbContext>()
            .UseOptions((_, options) =>
            {
                options.WithDefaultDataSource(DefaultDataSourceName, cs);
                options.WithShardingQuery((connStr, b) =>
                {
                    b.UseNpgsql(connStr);
                    b.ForRowState();
                    b.ConfigureWarnings(w => w.Ignore(CoreEventId.ManyServiceProvidersCreatedWarning));
                });
                options.WithShardingTransaction((conn, b) =>
                {
                    b.UseNpgsql(conn);
                    b.ForRowState();
                    b.ConfigureWarnings(w => w.Ignore(CoreEventId.ManyServiceProvidersCreatedWarning));
                });
                options.IgnoreCreateTableError = false;
            })
            .UseRouteOptions((_, routes) =>
            {
                // ★ 只注册要分片的表
                routes.AddTableRoute<B2cOrderMonthRoute>();
            });
    }
}
```

## 7. 在 EF 模块里注册分片（不要单独再开 Module）

与 Sample 一致：**EF 模块只做注册**（`AddSharding` / `UseShardingAfter`）；**Host 启动时**按固定顺序执行 `Migrate()` → `UseCompensate()`（见下方 Host 块）。

```csharp
using BeniceSoft.Abp.Auth.EntityFrameworkCore;
using BeniceSoft.Abp.EntityFrameworkCore.PostgreSql;
using BeniceSoft.Abp.EntityFrameworkCore.Sharding;
using Microsoft.EntityFrameworkCore.Diagnostics;
using Microsoft.Extensions.DependencyInjection;
using Volo.Abp.EntityFrameworkCore;
using Volo.Abp.Modularity;
using Wecharmer.WarehouseCenter.Sharding;

namespace Wecharmer.WarehouseCenter;

[DependsOn(
    typeof(AbpEntityFrameworkCorePostgreSqlModule),
    typeof(BeniceSoftAbpAuthEntityFrameworkCoreModule),
    typeof(BeniceSoftAbpEntityFrameworkCoreShardingModule),
    typeof(DomainModule)
)]
public class WarehouseCenterEntityFrameworkCoreModule : AbpModule
{
    public override void ConfigureServices(ServiceConfigurationContext context)
    {
        var configuration = context.Services.GetConfiguration();

        context.Services.AddAbpDbContext<WarehouseCenterDbContext>(options =>
        {
            options.AddDefaultRepositories(includeAllEntities: true);
        });

        WarehouseCenterShardingRegistrar.Configure(context.Services, configuration);

        Configure<AbpDbContextOptions>(options =>
        {
            options.Configure<WarehouseCenterDbContext>(ctx =>
            {
                ctx.UseNpgsql();
                // ForRowState（可选 Bulk/Hint）→ UseShardingAfter 必须最后
                ctx.DbContextOptions.UseShardingAfter<WarehouseCenterDbContext>(ctx.ServiceProvider, b =>
                {
                    b.ForRowState();
                    b.ConfigureWarnings(w => w.Ignore(CoreEventId.ManyServiceProvidersCreatedWarning));
                });
#if DEBUG
                ctx.DbContextOptions.EnableSensitiveDataLogging();
#endif
            });
        });

        context.Services.AddRowPermissionRepositories<WarehouseCenterDbContext>();
    }

    // 不在此处 Compensate：仅 Host 启动时 Migrate → UseCompensate
}
```

**Host 启动顺序（固定，唯一调用 UseCompensate 处）：**

```csharp
public override void OnApplicationInitialization(ApplicationInitializationContext context)
{
    using (var scope = context.ServiceProvider.CreateScope())
    {
        var db = scope.ServiceProvider.GetRequiredService<WarehouseCenterDbContext>();
        db.Database.Migrate(); // ① 先落实体物理表（开发期也可用 update-database / SQL 提前建好）
    }

    context.ServiceProvider.UseCompensate(); // ② 再创建带后缀的分表物理表
    // ... UseRouting 等
}
```

开发期也可在跑应用前单独执行：`dotnet ef database update` 或执行导出的 SQL（实体物理表先存在），再启动；启动时仍保留上述 **Migrate → UseCompensate**。
Host 仍只 `DependsOn(typeof(WarehouseCenterEntityFrameworkCoreModule))`，无需再挂第二个分片 Module。

## 8. Host（无需改 DependsOn 列表结构）

若 Host 本来就依赖 EF 模块，注册分片后**不用**再加 `XxxShardingModule`。确认 `ConnectionStrings:Default` 可用即可。

## 9. 连接串

单库分表时，`appsettings.json` 只需：

```json
{
  "ConnectionStrings": {
    "Default": "Host=...;Port=5432;Database=wecharmer_warehousecenter;Username=...;Password=..."
  }
}
```

不需要额外 `Ds1`（那是多数据源 / 分库才用）。

启动后，补偿会创建类似物理表：

```text
wh_b2c_orders_202401
wh_b2c_orders_202402
...
wh_b2c_orders_当前月
```

`wh_warehouses` / `wh_warehouselocations` 等仍是普通单表。

## 10. 业务代码怎么写（AppService / Repository）

继续用 `IRepository<B2cOrder, long>` / UoW，**不要**自己拼物理表名。

### 10.1 写入（自动按 OrderTime 落月表）

```csharp
await _orderRepo.InsertAsync(
    new B2cOrder(id, "B2C20240115001", 199.00m, new DateTime(2024, 1, 15)),
    autoSave: true);
```

### 10.2 查询：带分片键等值（推荐）

```csharp
var q = await _orderRepo.GetQueryableAsync();
var list = await q.AsNoTracking()
    .Where(x => x.OrderTime == orderTime && x.OrderNo == orderNo)
    .ToListAsync();
```

### 10.3 显式钉死物理尾缀（运维 / 补偿排查）

```csharp
using BeniceSoft.Abp.EntityFrameworkCore.Sharding;

var q = await _orderRepo.GetQueryableAsync();
var rows = await q.AsNoTracking()
    .AsRoute(ctx => ctx.MustTable[typeof(B2cOrder)] = new HashSet<string> { "202401" })
    .Where(x => x.Id == id)
    .ToListAsync();
```

注意：路由类必须 `EnabledHint => true`，否则 Must/Hint 无效。

### 10.4 与普通表同 UoW（合法且推荐演示）

```csharp
// 同一事务：改仓库（普通表）+ 写订单（分表）都可以
await _warehouseRepo.UpdateAsync(warehouse, autoSave: false);
await _orderRepo.InsertAsync(order, autoSave: false);
await uow.CompleteAsync();
```

## 12. 可选：再给订单加「分库」

若 B2C 订单还要按区域落到不同物理库（`ds0` / `ds1`）：

### 12.1 连接串

```json
{
  "ConnectionStrings": {
    "Default": "...;Database=wecharmer_wc_ds0;",
    "Ds1": "...;Database=wecharmer_wc_ds1;"
  }
}
```

### 12.2 分库路由

```csharp
public sealed class B2cOrderDataSourceRoute : DataSourceRoute<B2cOrder, string>
{
    private readonly List<string> _dataSources = ["ds0", "ds1"];

    protected override bool EnabledHint => true;

    public override void Configure(EntityMetadataDataSourceBuilder<B2cOrder> builder)
    {
        // 假设实体上有 Region 字段作为分库键
        builder.WithProperty(x => x.Region).WithAutoCreate(true);
    }

    public override IReadOnlyList<string> GetAll() => _dataSources;

    public override bool Add(string name)
    {
        if (_dataSources.Contains(name)) return false;
        _dataSources.Add(name);
        return true;
    }

    public override string GetKey(object shardingKey)
    {
        var region = shardingKey?.ToString() ?? string.Empty;
        return region.StartsWith("B", StringComparison.OrdinalIgnoreCase) ? "ds1" : "ds0";
    }
}
```

### 12.3 Registrar 中追加

```csharp
options.WithDefaultDataSource("ds0", ds0);
options.AdditionalDataSourceFactory = _ => new Dictionary<string, string>
{
    ["ds1"] = ds1
};

routes.AddTableRoute<B2cOrderMonthRoute>();
routes.AddDataSourceRoute<B2cOrderDataSourceRoute>();
```

### 12.4 写入约定

按库拆 UoW，避免一次提交跨物理库：

```csharp
using (var uow = _uow.Begin(requiresNew: true, isTransactional: true))
{
    await _orderRepo.InsertAsync(orderInDs0, autoSave: true);
    await uow.CompleteAsync();
}
using (var uow = _uow.Begin(requiresNew: true, isTransactional: true))
{
    await _orderRepo.InsertAsync(orderInDs1, autoSave: true);
    await uow.CompleteAsync();
}
```

## 13. 可选：取模分表（替代按月）

```csharp
public sealed class B2cOrderModRoute : ModIntTableRoute<B2cOrder>
{
    public B2cOrderModRoute() : base(length: 1, mod: 4) // 4 张表：_0 ~ _3
    {
    }

    protected override bool EnabledHint => true;

    public override void Configure(EntityMetadataTableBuilder<B2cOrder> builder)
    {
        builder.WithProperty(x => x.BucketKey) // int 分片键
            .WithSeparator("_")
            .WithAutoCreate(true);
    }
}
```

查询用 `BucketKey ==` 等值；`!=` 会扇出，业务层避免。

## 14. 常见问题

**Q：启用分片后，其它表会不会全部变分片？**  
A：不会。只有 `AddTableRoute` / `AddDataSourceRoute` 注册过的实体才分片。

**Q：新实体表谁建？分表物理表谁建？**  
A：按 §0 建表规范：  
1. **Migration**（`dotnet ef database update` 或导出 SQL 执行）建实体对应物理表——**必须先存在**。  
2. Host 启动：**先 `Migrate()`，再 `UseCompensate()`**；只为已 `AddTableRoute` 的实体建**带后缀**的分表物理表。  
禁止用 Compensate / `IF NOT EXISTS` 代替 Migration；禁止在 Migrate 之前 UseCompensate。

**Q：和 ABP 按租户拆库一起用？**  
A：**分片 DbContext 不要叠** `MultiTenantConnectionStringResolver`。逻辑多租户可保留；物理按租户分库用 `DataSourceRoute(TenantId)`。

**Q：Bulk 和分片怎么一起挂？**  
A：Module 同时 DependsOn PostgreSql + Sharding。Options：`UseNpgsql` → `ForRowState` → `UseShardingAfter`（分片必须最后）。物理库 `WithShardingQuery` 与壳共用同一套 Provider 配置。

**Q：IgnoreCreateTableError？**  
A：业务默认 `false`。仅引擎测试 Fixture 在重复 Compensate 时可 `true`。

**Q：Must / Hint 不生效？**  
A：路由里 `EnabledHint` 必须为 `true`。

**Q：可参考的可运行代码？**  
A：`BeniceSoft.Abp/samples`：

- `SampleEntityFrameworkCoreModule.cs`（`AddSharding` + `UseShardingAfter` 内联注册）
- `SampleHostModule.cs`（`Migrate` → `UseCompensate`）
- `Sharding/SampleShardingRoutes.cs`
- `Migrations/*`
- 联调：`/api/sample/sharding-sample/*`
- 引擎测试：`tests/...Sharding.Tests`（自建测试库；业务仍按 Migration → UseCompensate）

## 15. 一句话流程

```text
加包 → 实体 + ToTable → Migration 并 update-database/SQL
  → 需要分表则写 Route 并注册 → Host：Migrate 之后 UseCompensate
  → 业务用 IRepository + 分片键等值查询
```

仓库、库位等表**零改动**即可与 B2C 订单分表共存于同一服务。
