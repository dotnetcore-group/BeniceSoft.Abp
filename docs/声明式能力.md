# 声明式能力

缓存、分布式锁、限流、操作日志通过 ABP 动态代理拦截。

- Host 依赖 `AbpAutofacModule`。
- 方法为 `public virtual`，经注入的接口或类调用。类内部直接调用不拦截。
- 对应模块已 `DependsOn`。

## 缓存

模块：`BeniceSoftAbpCachingMessagePackModule` 或 `BeniceSoftAbpCachingSystemTextJsonModule`。连接：`Redis:Configuration`。

```json
"BeniceSoft": {
  "Caching": {
    "CacheKeyPrefix": "wh",
    "DefaultExpirationSeconds": 300
  }
}
```

```csharp
[Cacheable(Key = "order:{id}", ExpirationSeconds = 60, Unless = "__result__ == null")]
public virtual Task<OrderDto?> GetAsync(long id) => Task.FromResult<OrderDto?>(null);
```

可标在类或方法上。

- `Key`：表达式，参数名直接引用。未设置时用默认 `ICacheKeyGenerator`。
- `KeyGeneratorType`：实现 `ICacheKeyGenerator` 的具体类，无参构造。
- `Condition`：调用前执行。结果为 false 时不读、不写缓存。
- `Unless`：调用后执行。可用 `__result__`。结果为 true 时不写入。
- `ExpirationSeconds` 会再加 30–60 秒随机值。

## 分布式锁

模块：`BeniceSoftAbpDistributedLockModule`。连接：`DistributedLock:ConnectionString`。实现为 Redis Lua，可自动续期。

```csharp
[DistributedLock(ResourceId = "order:{id}", ExpiresMilliseconds = 60_000, AutoRenew = true)]
public virtual Task ShipAsync(long id) => Task.CompletedTask;
```

`ResourceId` 为 SmartFormat，花括号内为参数名。未取到锁抛 `SynchronizationLockException`（HTTP 423）。

`ExpiresMilliseconds` 默认 60000，`WaitMilliseconds` 默认 100，重试间隔默认 25。`AutoRenew` 在过期时间的一半续期。

代码加锁：`IDistributedLockProvider.TryAcquireAsync` / `AcquireAsync`。

## 限流

模块：`BeniceSoftAbpRateLimitingModule`，依赖 Redis。配置节 `RateLimiting`。`Enabled` 为 false 时不拦截。

```csharp
[RateLimit(LimitBy = RateLimitBy.UserId, PermitLimit = 5, WindowSeconds = 60)]
public virtual Task SendSmsAsync(string phone) => Task.CompletedTask;

[RateLimit(LimitBy = RateLimitBy.Custom, Key = "{phone}", PermitLimit = 1, WindowSeconds = 60)]
public virtual Task SendOnceAsync(string phone) => Task.CompletedTask;
```

`LimitBy`：`Ip`（默认）、`UserId`、`TenantId`、`Custom`、`Global`。`Key` 仅在 `Custom` 时生效，格式为 SmartFormat。

超限抛 `RateLimitExceededException`（HTTP 429）。`ThrowOnExceeded = false` 时只记日志，方法继续执行。

## 操作日志

分发模块二选一：

- `BeniceSoftAbpOperationLoggingEventBusModule`
- `BeniceSoftAbpOperationLoggingRedisModule`

```csharp
[OperationLog(OperationType = "Ship", BizModule = "Order")]
public virtual Task ShipAsync(long id, OperationLogContext log)
{
    log.BizId = id.ToString();
    log.BizCode = "SO-1";
    log.Remark = "发货";
    return Task.CompletedTask;
}
```

`OperationLogContext` 作为最后一个参数时，其中的 `BizId` 覆盖特性上的 `BizId`。分发失败只记日志。
