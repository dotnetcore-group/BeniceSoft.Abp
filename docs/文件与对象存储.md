# 文件与对象存储

## Excel

包：`BeniceSoft.Office.Excel`。无 `AbpModule`。入口 `ExcelMapper`。

`[ExcelColumn("订单号")]` 或 `[ExcelColumn(0)]` 指定列。`[ExcelIgnore]` 跳过属性。`[ExcelLastNonBlank]` 沿用上一非空单元格，用于合并单元格。

```csharp
var rows = new ExcelMapper(stream).Import<OrderRow>();
new ExcelMapper().Export(outputPath, rows, sheetIndex: 0);
```

`Take<T>` 返回 `ExcelRow<T>`：`RowNumber`、`Value`、`ErrorColumnIndex`、`ErrorMessage`。`maxErrorRows` 默认 10，达到后停止读取。`Import<T>` 只返回 `Value`。

`Put` / `Export` 按映射写表，`overwrite` 默认 true。已有版式用 `ExcelReport`。

## PDF

包：`BeniceSoft.Office.Pdf`。无 `AbpModule`。

```csharp
var doc = Pdf.Parse(bytes);
var withCode = Pdf.Parse(bytes, PdfParseOptions.WithBarcodes());
foreach (var page in Pdf.EnumeratePages(stream)) { }
```

默认解析文本和表单域，不渲染、不扫码。条码使用 `PdfParseOptions.WithBarcodes()`。逐页处理使用 `EnumeratePages`。

## 对象存储

包：`BeniceSoft.Abp.Extensions.ObjectStorage`。`DependsOn(typeof(BeniceSoftAbpObjectStorageModule))`。配置节 `ObjectStorage`。

```json
"ObjectStorage": {
  "DefaultProvider": "AliyunOss",
  "PublicBucketName": "wh-public",
  "PrivateBucketName": "wh-private",
  "PublicBaseUrl": "https://cdn.example.com"
}
```

`DefaultProvider`：`Local`、`AliyunOss`、`Minio`、`HuaweiObs`。

```csharp
var storage = resolver.Resolve();
await storage.PutAsync(new ObjectPutRequest
{
    Bucket = bucket,
    ObjectKey = objectKey,
    Content = stream,
    ContentType = "application/pdf"
});
var url = await storage.GetDownloadUrlAsync(bucket, objectKey, TimeSpan.FromMinutes(10));
```

`IObjectStorageResolver.Resolve()` 使用 `DefaultProvider`。`Resolve(StorageProviderType)` 指定提供方。公共对象 URL 由 `PublicBaseUrl` 与 objectKey 拼接。桶名：`ObjectStorageOptions.ResolveBucket(StorageAccessMode)`。未配置对应桶名时抛异常。

分片上传：`InitiateMultipartAsync`、`UploadPartAsync`、`CompleteMultipartAsync`。中止：`AbortMultipartAsync`。已上传分片：`ListPartsAsync`。

## 邮件

模块：`BeniceSoftAbpEmailingModule`。配置节 `Smtp`，替换 ABP `IEmailSender`。

```json
"Smtp": {
  "Host": "smtp.example.com",
  "Port": 465,
  "UserName": "noreply@example.com",
  "Password": "***",
  "EnableSsl": true,
  "DefaultFromAddress": "noreply@example.com",
  "DefaultFromDisplayName": "Wecharmer"
}
```

端口 465 强制 SSL。未设置 `DefaultFromAddress` 时使用 `UserName`。
