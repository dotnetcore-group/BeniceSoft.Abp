# 动态查询

请求实现 `IDynamicQueryRequest`，模型在 `BeniceSoft.Core`。LINQ：`BeniceSoft.Abp.Extensions.DynamicQuery.EfCore`。SQL：`BeniceSoft.Abp.Extensions.DynamicQuery.Sql`。`IQueryableWrapper.DynamicQueryBy` 调用的是 EF 扩展。

## 请求

```csharp
public class OrderQuery : IDynamicQueryRequest
{
    public List<DynamicQueryConditionGroup>? ConditionGroups { get; set; }
}
```

`DynamicQueryConditionGroup` 含 `Relation` 和 `Conditions`。组内、组间用 `Relation` 组合，值为 `and` 或 `or`，默认 `and`。

| 字段 | 含义 |
|------|------|
| `FieldName` | 属性名，支持 `a.b`。SQL 侧为列名 |
| `FieldType` | `integer` / `long` / `double` / `decimal` / `string` / `date` / `datetime` / `boolean` / `guid` |
| `Operator` | `ExprOperator` |
| `Value` | 字符串列表。`Between`、`In` 使用多个元素 |
| `Relation` | `and` 或 `or` |

`ExprOperator`：`Equal`、`NotEqual`、`GreaterThan`、`GreaterThanOrEqual`、`LessThan`、`LessThanOrEqual`、`Contains`、`NotContains`、`StartsWith`、`EndsWith`、`Between`、`In`、`NotIn`。JSON 可用枚举名或 `EnumMember`（`equal`、`not_equal`、`in` 等）。

`ConditionGroups` 为空时不加条件。`FieldName` 为空的条件跳过。未知 `FieldType` 抛 `DynamicQueryException`。

不会自动附加租户或分片键条件。

## EF

```csharp
query = query.DynamicQueryBy(request);
query = query.DynamicQueryBy(request, out var expressionText);
query = query.DynamicQueryBy(request, skipNullableCheck: true);
```

`skipNullableCheck` 默认 false。`FieldName` 不是目标类型的属性时，表达式构建失败。

## SQL

原 SQL 作为子查询，外层追加 WHERE，返回 SqlKata `SqlResult`。

已实现的操作符：`Equal`、`NotEqual`、`In`。其余操作符抛 `ArgumentOutOfRangeException`。

```csharp
var result = """
    SELECT * FROM wh_orders
    """.DynamicQueryBy(request, SqlCompilerType.Postgres);

await sqlExecuter.QueryAsync<Order>(result.Sql, result.NamedBindings);
```

`SqlCompilerType`：`SqlServer`（默认）、`MySql`、`Postgres`、`Oracle`、`Sqlite`、`Firebird`。
