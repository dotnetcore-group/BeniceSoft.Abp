# 领域与应用服务

实体主键 `long`，时间 `DateTimeOffset`。应用服务继承 `BeniceSoftApplicationService`，返回 DTO 或 `PagedList<T>`。

## 实体

| 场景 | 基类 |
|------|------|
| 聚合根，创建/修改 | `BeniceSoftAuditedAggregateRoot<long>` |
| 聚合根，软删 | `BeniceSoftFullAuditedAggregateRoot<long>` |
| 聚合根，软删 + 租户 | `BeniceSoftFullAuditedMultiTenantAggregateRoot<long>` |
| 非聚合根，同上三档 | `BeniceSoftAuditedEntity<long>` / `BeniceSoftFullAuditedEntity<long>` / `BeniceSoftFullAuditedMultiTenantEntity<long>` |

`BeniceSoftAbpDbContext` 在 SaveChanges 写入：

- `CreationTime` / `CreatorId` / `CreatorName`
- `LastModificationTime` / `LastModifierId` / `LastModifierName`
- 软删：`IsDeleted` / `DeletionTime` / `DeleterId` / `DeleterName`
- 多租户：`TenantId`（`Guid?`）

`CreatorId`、`LastModifierId` 为 `long`。姓名为字符串。时钟：`AbpClockOptions.Kind = DateTimeKind.Utc`。

## 应用服务

```csharp
public class OrderAppService : BeniceSoftApplicationService
{
    public async Task<OrderDto> GetAsync(long id)
    {
        var userId = CurrentUser.Id;
        // ...
    }
}
```

`CurrentUser` 为 `IBeniceSoftCurrentUser`：`Id`、`TenantId`、`UserName`、`Name`、`ClientId`、`Roles`。未认证时 `IsAuthenticated` 为 false，`Id` 为 null。

```csharp
var queryable = await _orderRepository.GetQueryableAsync();
var page = await QueryableWrapperFactory.CreateWrapper(queryable)
    .AsNoTracking()
    .WhereIf(!input.OrderNo.IsNullOrWhiteSpace(), x => x.OrderNo.Contains(input.OrderNo!))
    .DynamicQueryBy(input)
    .OrderByDescending(x => x.CreationTime)
    .ToPagedListAsync(input.PageNumber, input.PageSize);
```

`IQueryableWrapper<T>`：`Include`、`SearchByKey`、`PageBy` / `PageByNumber`、`ToListAsync`、`CountAsync`、`AsQueryable`。

原生 SQL：`ISqlExecuter<TContext>`。`QueryAsync` / `QueryFirstAsync` / `ExecuteAsync`。

## 响应

`JsonFormatResponseFilter` 将 Action 结果包装为：

```json
{ "code": 200, "message": "", "data": { } }
```

返回值已是 `ResponseResult` 时不再包装。`204` 和空结果的 `code` 为 200。

跳过包装：`[IgnoreJsonFormat]`，或请求头 `X-Ignore-Json-Format`。

业务错误抛 `UserFriendlyException`。中间件映射：

| 异常 | code |
|------|------|
| `UserFriendlyException` / `AbpValidationException` | 400 |
| `NoAuthorizationException`（含未认证 401） | 401 |
| `EntityNotFoundException` | 404 |
| `SynchronizationLockException` | 423 |
| `RateLimitExceededException` | 429 |
| `AbpRemoteCallException` | 503 |
| 其它 | 500，message 为「系统出现不可预期的错误」 |

带远程调用头的请求走 ABP `RemoteServiceErrorResponse`，不转 `ResponseResult`。需要自行构造状态码的接口直接返回 `ResponseResult`。
